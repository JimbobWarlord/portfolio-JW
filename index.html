UX Design Work

For a UX specialisation class, I designed a prototype interface for a mobile cooking app known as ICanCook! (Great name, I know) I created the design using Figma and I was able to implement several features ranging from being able to view productive video tutorials, to bookmarking recipes, to a level-up system as users cooked more!
